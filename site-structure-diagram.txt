DATA FLOW DIAGRAM
=================

User Interaction → Lead Capture
│
├─ Option 1: Contact Form
│  └─ Form Submit → Netlify Function (/netlify/functions/lead.js)
│     └─ Validation (email format, message length, honeypot check)
│        └─ Zapier Webhook
│           └─ HubSpot (Create/Update Contact + Optional Deal)
│
├─ Option 2: Calendly Widget
│  └─ Direct booking (Calendly handles data)
│     └─ Calendly → Your Calendar + HubSpot (via Calendly integration)
│
└─ Tracking (Parallel)
   ├─ GA4 Events (page views, CTA clicks, form submits)
   └─ HubSpot Tracking (session data, page flows)


CONTENT MANAGEMENT FLOW
========================

Content Editor (Client)
└─ Logs into /admin (Netlify Identity)
   └─ Decap CMS Interface
      ├─ Collections
      │  ├─ Services (src/content/services/)
      │  ├─ Locations (src/content/locations/)
      │  ├─ Case Studies (src/content/case-studies/)
      │  ├─ Blog Posts (src/content/blog/)
      │  └─ Settings (src/content/settings/site.json)
      │
      └─ Editorial Actions
         ├─ Create New Entry → Git commit to branch
         ├─ Edit Entry → Git commit
         └─ Publish → Merge to main
            └─ Trigger Netlify Build
               └─ Astro Build Process
                  ├─ Generate Static HTML
                  ├─ Optimize Images
                  ├─ Create Sitemap
                  └─ Deploy to CDN


SEO + SCHEMA IMPLEMENTATION
============================

Every Page:
├─ <meta> tags (title, description)
├─ Open Graph tags (og:title, og:description, og:image)
├─ Twitter Card tags
└─ Canonical URL

Homepage:
└─ JSON-LD: Organization
   ├─ name
   ├─ url
   ├─ logo
   ├─ sameAs (social links)
   └─ contactPoint

Service Pages:
└─ JSON-LD: Service + FAQPage
   ├─ Service: name, description, provider, areaServed
   └─ FAQPage: mainEntity (array of Questions/Answers)

Location Pages:
└─ JSON-LD: LocalBusiness
   ├─ name, address (or areaServed if no physical location)
   ├─ geo coordinates (if applicable)
   └─ openingHours (if applicable)

Case Study Pages:
└─ JSON-LD: Article (optional)
   └─ headline, author, datePublished


RESPONSIVE BREAKPOINTS
=======================

Mobile First Approach:
├─ Base (< 640px): Single column, stacked navigation
├─ SM (640px+): Improved spacing, 2-col grids where appropriate
├─ MD (768px+): Tablet optimizations, side-by-side forms
├─ LG (1024px+): Desktop nav, 3-col grids, hero layouts
└─ XL (1280px+): Max-width containers, enhanced spacing


PERFORMANCE BUDGET TARGETS
===========================

Lighthouse Scores (Mobile):
├─ Performance: ≥ 90
├─ Accessibility: ≥ 90
├─ Best Practices: ≥ 90
└─ SEO: 100

Page Speed:
├─ First Contentful Paint: < 1.8s
├─ Largest Contentful Paint: < 2.5s
├─ Total Blocking Time: < 200ms
└─ Cumulative Layout Shift: < 0.1

Asset Budgets:
├─ HTML: < 50KB per page
├─ CSS: < 100KB total
├─ JS: < 200KB total (initial)
├─ Images: WebP format, lazy loaded, < 200KB each
└─ Fonts: WOFF2, 2 weights max per family
